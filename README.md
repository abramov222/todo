# To-Do List (Tailwind CSS + vanilla JS)

Приложение для ведения списка задач: добавление через модальное окно, редактирование, удаление, отметка о выполнении, поиск по названию и переключение светлой/тёмной темы. Задачи и выбранная тема сохраняются в `localStorage`. Интерфейс адаптивный и рассчитан на работу с клавиатуры и скринридером.

Это Tailwind-версия приложения из ветки `lab-4` (Sass): функциональность и внешний вид те же, оформление полностью на утилитах Tailwind.

**Автор:** Илья Абрамов, группа ФИТ-241

## Технологии

- HTML5, нативное модальное окно `<dialog>`
- Tailwind CSS v4, сборка через `@tailwindcss/cli`
- Тёмная тема через вариант `dark:`, привязанный к атрибуту `data-theme`
- vanilla JS

## Структура

```
src/input.css   — подключение Tailwind, вариант dark и цвета палитры (@theme)
js/main.js      — логика приложения
index.html      — разметка с утилитами Tailwind
```

Скрипт не зависит от классов оформления: для поиска элементов используются классы `js-*` и `data`-атрибуты, а состояние выполненной задачи передаётся атрибутом `data-done`, на который реагирует вариант `group-data-[done=true]:`.

## Установка и запуск

```bash
npm install
npm run build          # сборка CSS в dist/css/main.css
```

Во время разработки:

```bash
npm run tailwind:dev   # пересобирает CSS при изменении файлов
```

Затем откройте `index.html` через локальный сервер, например `npx serve .` или расширение Live Server в VS Code.

## Доступность

- Все действия выполняются нативными `<button>`, `<input>` и работают с клавиатуры.
- Кнопки «Редактировать» и «Удалить» получают имя с названием задачи через `aria-labelledby`, поэтому оно обновляется после переименования.
- У чекбоксов, поля поиска и поля формы есть связанные `<label>` (скрытые подписи — через `sr-only`).
- Модальное окно на `<dialog>` + `showModal()`: фокус в поле названия, закрытие по Esc, возврат фокуса на кнопку, открывшую окно.
- После удаления задачи фокус переходит на соседнюю видимую задачу или на кнопку «Добавить задачу».
- Видимый фокус через `focus-visible:`, контраст текста не ниже 4.5:1 в обеих темах, выполненная задача зачёркнута и отмечена галочкой, анимации отключаются через `motion-reduce:`.
