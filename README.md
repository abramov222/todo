# To-Do List (Vue 3 + Vite)

Приложение для ведения списка задач, перенесённое с vanilla JS на Vue 3: добавление через модальное окно, редактирование, удаление, отметка о выполнении, поиск по названию и переключение светлой/тёмной темы. Задачи и выбранная тема сохраняются в `localStorage`. Оформление на Sass сохранено из лабораторной №4, интерфейс адаптивный и доступный с клавиатуры.

**Автор:** Илья Абрамов, группа ФИТ-241

**Опубликованное приложение:** https://abramov222.github.io/todo/

## Технологии

- Vue 3, Composition API (`<script setup>`)
- Vite — сервер разработки и сборка
- Sass (SCSS): модули `@use`/`@forward`, переменные, карты, миксины, БЭМ; темы через CSS custom properties
- GitHub Actions + GitHub Pages — публикация

## Структура

```
src/
├─ components/
│  ├─ TodoItem.vue      — задача: чекбокс, название, кнопки редактирования и удаления
│  ├─ TodoList.vue      — раздел «Активные» / «Выполненные» со списком или сообщением о пустом списке
│  ├─ AddTodoModal.vue  — модальное окно на <dialog> с формой создания и редактирования
│  ├─ SearchBar.vue     — поле поиска (v-model)
│  └─ ThemeToggle.vue   — переключатель темы
├─ App.vue              — состояние приложения и обработка действий
├─ storage.js           — чтение и запись localStorage
└─ main.js              — монтирование приложения и подключение стилей
scss/                   — стили из лабораторной №4
```

Состояние задач, строка поиска и тема хранятся в `App.vue` (`ref`) и передаются дочерним компонентам через `props`. Компоненты сообщают о действиях событиями `emit` (`toggle`, `edit`, `delete`, `save`, `close`), а сами данные меняет только `App.vue`. Отфильтрованный список, разделение на активные и выполненные задачи и счётчик «Выполнено N из M» — `computed`.

## Где применены `watch` и `v-if`

**`watch`:**
- `App.vue` — наблюдение за массивом задач (`deep: true`): при любом изменении (добавление, переименование, отметка, удаление) список записывается в `localStorage`. Сохранение — побочный эффект, поэтому вынесено в `watch`, а не разбросано по обработчикам.
- `App.vue` — наблюдение за темой: выставляет атрибут `data-theme` на `<html>` и запоминает выбор.
- `AddTodoModal.vue` — наблюдение за пропом `open`: нативный `<dialog>` открывается методом `showModal()` и закрывается `close()`, поэтому состояние из props синхронизируется с DOM вручную. Так сохраняется поведение `<dialog>` с клавиатуры: фокус внутри окна, Esc, недоступный фон.

**`v-if`:**
- `TodoList.vue` — если в разделе есть задачи, выводится список, иначе (`v-else`) сообщение «Активных задач нет» / «Ничего не найдено». Пустой `<ul>` не попадает в разметку.
- `ThemeToggle.vue` — показывает иконку луны или солнца в зависимости от текущей темы.

## Установка и запуск

```bash
npm ci             # установка зависимостей по package-lock.json
npm run dev        # сервер разработки Vite
npm run build      # сборка в dist/
npm run preview    # просмотр собранной версии
```

## Публикация

Сборка публикуется на GitHub Pages через GitHub Actions (`.github/workflows/ci.yaml`): после push в ветку workflow устанавливает зависимости, выполняет `npm run build` и выкладывает папку `dist/`. В `vite.config.js` указан `base: '/todo/'`, чтобы пути к файлам сборки совпадали с адресом `https://abramov222.github.io/todo/`. В настройках репозитория выбран источник **Settings → Pages → Source: GitHub Actions**.

## Доступность

Сохранены требования A1–A7 из лабораторной №4: все действия выполняются нативными кнопками и полями с клавиатуры; кнопки задач получают имя с названием задачи через `aria-labelledby`; у полей есть `<label>`; модальное окно возвращает фокус на кнопку, которая его открыла; после удаления фокус переходит на соседнюю задачу; фокус виден у всех элементов, контраст не ниже 4.5:1 в обеих темах.
