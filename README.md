# To-Do List (Sass + vanilla JS)

Приложение для ведения списка задач: добавление через модальное окно, редактирование, удаление, отметка о выполнении, поиск по названию и переключение светлой/тёмной темы. Задачи и выбранная тема сохраняются в `localStorage`. Интерфейс адаптивный и рассчитан на работу с клавиатуры и скринридером.

**Автор:** Илья Абрамов, группа ФИТ-241

## Технологии

- HTML5, нативное модальное окно `<dialog>`
- Sass (SCSS): модули `@use`/`@forward`, переменные, карты, функции, миксины, БЭМ
- Темы через CSS custom properties, сгенерированные из Sass-карт
- vanilla JS
- npm / sass-cli — сборка стилей

## Структура

```
scss/
├─ utils/       — переменные, rem(), миксины (respond-to, visually-hidden, focus-ring, stroke-icon)
├─ base/        — сброс стилей, класс visually-hidden
├─ layout/      — контейнер приложения, шапка, панель поиска
├─ components/  — кнопки, переключатель темы, поиск, секции и элементы задач, модальное окно, поле формы
├─ themes/      — карты светлой/тёмной палитры → CSS-переменные
└─ main.scss    — точка входа
js/main.js      — логика приложения
```

Для JS используются классы `js-*` и `data`-атрибуты, классы оформления в скриптах не участвуют.

## Установка и запуск

```bash
npm install
npm run build      # сборка стилей в dist/css/main.css
```

Во время разработки стилей:

```bash
npm run sass:dev   # пересобирает CSS при каждом сохранении .scss
```

Затем откройте `index.html` через локальный сервер, например `npx serve .` или расширение Live Server в VS Code.

## Доступность

- Все действия выполняются нативными `<button>`, `<input>` и работают с клавиатуры.
- Кнопки «Редактировать» и «Удалить» получают имя с названием задачи через `aria-labelledby`, поэтому оно обновляется после переименования.
- У чекбоксов, поля поиска и поля формы есть связанные `<label>`.
- Модальное окно на `<dialog>` + `showModal()`: фокус в поле названия, закрытие по Esc, возврат фокуса на кнопку, открывшую окно.
- После удаления задачи фокус переходит на соседнюю видимую задачу или на кнопку «Добавить задачу».
- Видимый `:focus-visible` у всех интерактивных элементов, контраст текста не ниже 4.5:1 в обеих темах, выполненная задача зачёркнута и отмечена галочкой.
- Изменения списка озвучиваются через область `role="status"`.
